* Rust

Rust 的結構由內建 [[info:emacs#Parsing Program Source][tree-sitter]] mode 讀，語義交給
[[https://rust-analyzer.github.io/][rust-analyzer]]，調試交給 Dape 已有的 =lldb-dap= 配置。這個模塊只把三者接到既有

** 主模式與 grammar

Emacs 30 自帶 =rust-ts-mode=，卻沒有不依賴 grammar 的 =rust-mode=。後者由 NonGNU ELPA
補上，並且刻意不讓它自己轉成 tree-sitter 派生模式：grammar 壞掉時 fallback 必須真的
不再依賴 grammar。

兩套 mode 都保持 Rust 慣例的四格空白。EditorConfig 已認識兩個變量，項目聲明仍會在
mode hook 之後覆蓋這裏的默認值。

#+begin_src emacs-lisp :tangle "modules/ginshio/ginshio-lang-rust.el"
(use-package rust-mode
  :straight t
  :mode ("\\.rs\\'" . rust-mode)
  :init
  (setq rust-mode-treesitter-derive nil
        rust-indent-offset 4
        rust-format-on-save nil))

(setq rust-ts-mode-indent-offset 4)

(ginshio-lang-register
 :module 'lang-rust
 :grammars '((rust "https://github.com/tree-sitter/tree-sitter-rust" "v0.23.2"))
 :compilers '(("rustc" ("rustc")
               :remedy "rustup toolchain install stable"))
 :modes '((rust-mode rust-ts-mode rust)))
#+end_src

=v0.23.2= 是 Emacs 30 可使用的 ABI 14 grammar；這份配置支持的 tree-sitter runtime
仍能向後載入它。系統打包的 grammar 照既有策略優先，本地 revision 只在系統沒有時使用。

** 診斷

=rust-ts-mode= 會自行加入一個每次把整份 buffer 喂給 =clippy-driver= 的 Flymake backend。
Eglot 接管時會保存並暫時替換它，避免和 rust-analyzer 重複；關閉 Eglot、server 缺失或
文件不屬於 project 時，原本的 backend 仍然可用。它的命令是 standalone 的
clippy-driver，解析不了 Cargo 依賴，所以它的診斷只在腳本式的孤立文件上完整；項目內
的語義本來就歸 rust-analyzer，那裏的後備價值主要是「server 起不來時還有點東西看」。

** rust-analyzer

#+begin_src emacs-lisp :tangle "modules/ginshio/ginshio-lang-rust.el"
(ginshio-lsp-register-server
 :modes '(rust-mode rust-ts-mode)
 :program "rust-analyzer"
 :contact '("rust-analyzer"))
#+end_src

沒有項目或 executable 時，lsp 框架不自動啓動；~M-m c e~ 仍可手動要求並看到原始錯誤。
格式化能力則沿用 lsp 模塊的全局決定，不由 rust-analyzer 改寫 buffer。

** 調試與自檢

Dape 0.27 的 =lldb-dap= 配置已列出兩個 Rust mode，不需要複製 adapter。選配置後只需把
~:program~ 改成 Cargo 產生的可執行文件，例如 =target/debug/demo=；固定值仍應寫在項目的
=.dir-locals.el=。

#+begin_src emacs-lisp :tangle "modules/ginshio/ginshio-lang-rust.el"
(ginshio-doctor-executable 'lang-rust "lldb-dap"
                           :severity 'warn
                           :note "debug adapter"
                           :remedy "zypper install lldb")
#+end_src

rustc 與 grammar 檢查由 lang 註冊產生；rust-analyzer 的必要檢查由 lsp 註冊自動產生。

#+begin_src emacs-lisp :tangle "modules/ginshio/ginshio-lang-rust.el" :comments no
(provide 'ginshio-lang-rust)
;;; ginshio-lang-rust.el ends here
#+end_src
