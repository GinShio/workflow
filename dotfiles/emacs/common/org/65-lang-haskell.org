* Haskell

Classic 編輯使用成熟的 [[https://github.com/haskell/haskell-mode][haskell-mode]]；普通 =.hs= 在 grammar 可用時改用
[[https://codeberg.org/pranshu/haskell-ts-mode][haskell-ts-mode]]。語義由
[[https://haskell-language-server.readthedocs.io/][Haskell Language Server]] 提供，調試則沿用 Dape 的 =hdb= 配置。

TS mode 的 canonical repository 在 Codeberg；recipe 從
[[https://github.com/emacsmirror/haskell-ts-mode][Emacsmirror]] 的逐 commit 鏡像取得，最後仍由 lock file 固定 revision。

** Classic mode

Haskell layout 是語法的一部分，fallback 使用 haskell-mode 經過多年使用的互動縮進器。
五個 offset 都設成二，只是沒有項目聲明時的起點；Emacs 30 的 EditorConfig 已認識它們。

Literate Haskell 與預處理過的 source 不是普通 =.hs=：它們保留專門的 classic mode，不被
TS dispatcher 一併吞掉。

#+begin_src emacs-lisp :tangle "modules/ginshio/ginshio-lang-haskell.el"
(use-package haskell-mode
  :straight t
  :mode (("\\.\\(?:hs\\|hs-boot\\|hsig\\|hsc\\|gs\\)\\'" . haskell-mode)
         ("\\.\\(?:lhs\\|lgs\\)\\'" . haskell-literate-mode))
  :init
  (setq haskell-indentation-layout-offset 2
        haskell-indentation-starter-offset 2
        haskell-indentation-left-offset 2
        haskell-indentation-where-pre-offset 2
        haskell-indentation-where-post-offset 2))
#+end_src

** 手動 Tree-sitter mode

=haskell-ts-mode= 上游目前刻意把縮進關掉：既有規則仍在重寫，而且修一種 layout 會破壞
另一種。因此普通 =.hs= 固定使用可靠的 classic mode；需要 tree-sitter 的 font-lock、
outline 與結構導航時，顯式調用 ~ginshio/haskell-ts-mode~。上游留下的 electric newline
hook 仍會修改縮進，手動 TS mode 中也一併摘掉。

#+begin_src emacs-lisp :tangle "modules/ginshio/ginshio-lang-haskell.el"
(defconst ginshio-lang-haskell-classic-entry
  '("\\.hs\\'" . haskell-mode)
  "Auto-mode entry which keeps ordinary Haskell editing reliable.")

(defun ginshio-lang-haskell-prefer-classic-h ()
  "Keep classic Haskell ahead of the TS package's file association."
  (setq auto-mode-alist
        (cons ginshio-lang-haskell-classic-entry
              (delete ginshio-lang-haskell-classic-entry
                      auto-mode-alist))))

(use-package haskell-ts-mode
  :straight (haskell-ts-mode :host github :repo "emacsmirror/haskell-ts-mode")
  :commands haskell-ts-mode
  :init
  (setq haskell-ts-use-indent nil
        haskell-ts-font-lock-level 4
        haskell-ts-ghci "ghci")
  :config
  (ginshio-lang-haskell-prefer-classic-h))

(defun ginshio-lang-haskell-disable-ts-indent-h ()
  "Keep the intentionally disabled Haskell TS indentation fully disabled."
  (setq-local electric-indent-functions
              (delq #'haskell-ts-indent-after-newline
                    electric-indent-functions)))

(add-hook 'haskell-ts-mode-hook
          #'ginshio-lang-haskell-disable-ts-indent-h)

(ginshio-lang-register
 :module 'lang-haskell
 :grammars '((haskell "https://github.com/tree-sitter/tree-sitter-haskell"
                      "v0.23.1"))
 :compilers '(("ghc" ("ghc")
               :remedy "ghcup install ghc")))

(defun ginshio/haskell-ts-mode ()
  "Enter structural Haskell mode when its grammar is usable."
  (interactive)
  (unless (ginshio-lang-grammar-ready-p 'haskell)
    (user-error "The Haskell tree-sitter grammar is unavailable"))
  (haskell-ts-mode))

(ginshio-lang-haskell-prefer-classic-h)
#+end_src

TS mode 在這個狀態下提供高亮、imenu、結構導航與摺疊，但 =TAB= 沒有一套可承諾正確的
Haskell layout 規則。回到可靠編輯用 ~M-x haskell-mode~；等上游完成重寫後再審查是否
恢復自動 remap。

** HLS

Eglot 從 mode 名推導 language id；=haskell-literate-mode= 會被誤推成
=haskell-literate=。HLS 要的仍是 =haskell=，所以在 Eglot 建立 server 表之前把這個穩定
外部名稱放到 mode symbol 上。

#+begin_src emacs-lisp :tangle "modules/ginshio/ginshio-lang-haskell.el"
(put 'haskell-literate-mode 'eglot-language-id "haskell")

(ginshio-lsp-register-server
 :modes '(haskell-mode haskell-ts-mode haskell-literate-mode)
 :program "haskell-language-server-wrapper"
 :contact '("haskell-language-server-wrapper" "--lsp"))
#+end_src

** 調試與自檢

Dape 0.27 的 =hdb= 已經覆蓋 classic、TS 與 literate modes，因此不複製配置。它需要
well-typed 的 =hdb= adapter；項目入口和參數仍在啓動時編輯，或寫入 =.dir-locals.el=。

#+begin_src emacs-lisp :tangle "modules/ginshio/ginshio-lang-haskell.el"
(ginshio-doctor-executable 'lang-haskell "ghci"
                           :severity 'warn
                           :note "interactive Haskell"
                           :remedy "ghcup install ghc")

(ginshio-doctor-executable 'lang-haskell "hdb"
                           :severity 'warn
                           :note "Haskell debug adapter"
                           :remedy "install haskell-debugger and put hdb on PATH")
#+end_src

ghc 與 grammar 檢查由 lang 註冊產生；HLS 的必要檢查由 lsp 註冊產生。

#+begin_src emacs-lisp :tangle "modules/ginshio/ginshio-lang-haskell.el" :comments no
(provide 'ginshio-lang-haskell)
;;; ginshio-lang-haskell.el ends here
#+end_src
