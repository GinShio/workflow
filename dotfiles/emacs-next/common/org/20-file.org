* 文件

文件管理器通常是一個帶圖標的窗格：你點，它做。dired 給的是另一樣東西——一個目錄被列
成一段文本，而那段文本是緩衝區。搜索目錄用的是搜索緩衝區的鍵，挑出一批文件用的是標
記，批量改名用的是編輯。你已經會的操作在這裏原樣適用，不必再學一套。

代價是它不替你決定任何事。下面調的幾乎都是默認值，而那些默認值是為另一個年代選的：
那時磁盤很慢、終端很窄、目錄裏不會有三百個文件。

Dired 與可編輯目錄的完整手冊分別是 [[info:emacs#Dired][Emacs manual: Dired]] 和
[[info:emacs#Wdired][Emacs manual: Wdired]]；文件比較見 [[info:ediff#Top][Ediff manual]]。從「標記一批文件」到批量改名、
比較與桌面打開的最短路徑在 [[file:../GUIDE.org::*文件與 Dired][GUIDE.org]]。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el" :comments no
;;; ginshio-file.el --- directories as buffers -*- lexical-binding: t; -*-
#+end_src

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(require 'ginshio-path)
(require 'ginshio-doctor)
(require 'ginshio-keys)
(require 'dired)
(require 'dired-aux)
#+end_src

** 逛過的目錄不要留下來

出廠行為是每進一層目錄開一個新緩衝區。逛十層留十個，而其中九個你再也不會回去看。它
們不佔什麼內存，佔的是後面每一次切緩衝區時的注意力。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(setq dired-kill-when-opening-new-dired-buffer t)
#+end_src

回上一層仍然可以，因為那也是「進入一個目錄」，走的是同一條路。真要並排看兩個目錄，
在另一個窗口裏開第二個 dired 就是了——下面那條 dwim 規則正是為這種情形準備的。

** 列出什麼

默認的 =-al= 有兩個問題：它列出 =.= 和 =..= 這兩個永遠沒用的條目，而且目錄和文件混
在一起按字母排。=-A= 去掉前者，=--group-directories-first= 解決後者。

時間戳用 ISO 格式，因為出廠格式在半年前後會換一種寫法——半年之內顯示時分，之外顯示
年份——於是同一列裏出現兩種寬度不同的東西，掃過去對不齊。

=-v= 讓 =file2= 排在 =file10= 前面。按字符串排序時 =10= 小於 =2=，這在任何帶編號的
目錄裏都是錯的。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(setq dired-listing-switches
      "-Ahlv --group-directories-first --time-style=long-iso")
#+end_src

這串開關裏有三個是 GNU coreutils 的擴展。本機沒有問題，遠程主機不一定——遠程列目錄
用的是那台機器上的 =ls=。remote 模塊為此單獨給遠程連接換一串保守的開關。

權限、屬主、大小這些列平時是噪音，需要的時候按 =(= 調出來。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(add-hook 'dired-mode-hook #'dired-hide-details-mode)
#+end_src

磁盤上變了就重新讀，但只在確實變了的時候讀——每次切回緩衝區都無條件重列，大目錄下能
感覺得到。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(setq dired-auto-revert-buffer #'dired-directory-changed-p)
#+end_src

搜索時只匹配文件名。一個目錄列表裏，日期和大小構成的數字串很容易撞上你要找的東西。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(setq dired-isearch-filenames 'dwim)
#+end_src

** 兩個窗口就是來源和去處

並排開着兩個 dired 時，複製的目標幾乎必然是另一邊。這條規則讓 =C= 和 =R= 直接把另一
個窗口的目錄填成默認值，於是雙窗口文件管理器的操作方式就成立了：左邊標記，右邊是去
處，按 =C=。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(setq dired-dwim-target t)
#+end_src

複製和刪除目錄時不再逐層追問。出廠設置只對頂層放行，往下每一級都要你再答一次——而你
在按下那個鍵之前就已經知道自己在對一棵樹動手。

目標路徑上缺目錄時問一句而不是報錯；用 git 管着的文件改名時走 git，這樣改名不會在版
本控制眼裏變成一刪一增。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(setq dired-recursive-copies 'always
      dired-recursive-deletes 'always
      dired-create-destination-dirs 'ask
      dired-vc-rename-file t)
#+end_src

真正大的複製、移動、打包不放在這裏。它們會把 Emacs 卡住直到做完，而終端在這件事上做
得更好：有進度、可以中斷、關掉窗口它也繼續。dired 擅長的是挑出哪些文件，不是搬運它
們。

** 改名就是改文本

wdired 把目錄列表變成可寫的：改文件名就是改那一行文字，保存時一併執行。配合多光標或
者矩形，重命名一百個文件和重命名一個是同一個動作。

它出廠掛在 =C-x C-q= 上，而這份配置沒有 =C-x=。dired 自己的映射並沒有把這個序列收進
去，靠的是全域的 =C-x= 前綴，所以清空全域之後它就消失了——不報錯，只是按下去什麼也不
發生。換一個 dired 沒用過的字母。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(keymap-set dired-mode-map "r" #'dired-toggle-read-only)
#+end_src

挑 =r= 是因為它旁邊就是 =R=：一個改一個名字，一個進去改一批。

權限也可以在同一個緩衝區裏改。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(setq wdired-allow-to-change-permissions t)
#+end_src

改完 =C-c C-c= 執行，=C-c C-k= 放棄——這兩個鍵在 major mode 自己的映射裏，不受全域影
響。

** 比較

=​=​= 出廠調用的是 =diff=，結果是一個只讀的補丁緩衝區。ediff 給的是並排的兩欄、逐塊
高亮、可以把任一側搬到另一側去，而它在 vc 模塊裏已經配置好了窗口佈局。

標記的文件數量決定比較什麼：標一個就再問你另一個，標兩個或三個就直接比。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(defun ginshio/dired-ediff ()
  "Compare the marked files.
One marked file is compared against another you are asked for; two or
three are compared with each other."
  (interactive)
  (let* ((files (dired-get-marked-files))
         (count (length files)))
    (pcase count
      (1 (ediff-files (car files)
                      (read-file-name "Compare with: "
                                      (dired-dwim-target-directory))))
      (2 (apply #'ediff-files files))
      (3 (apply #'ediff-files3 files))
      (_ (user-error "Mark one, two or three files; %d marked" count)))))

(keymap-set dired-mode-map "=" #'ginshio/dired-ediff)
#+end_src

** 交給桌面

=E= 用系統註冊的程序打開光標下的文件——PDF 交給閱讀器，視頻交給播放器。這是內建的，
不需要配置，但值得知道它在那裏：它劃出了 Emacs 該管到哪為止的那條線。

** 縮略圖放哪

看圖片時生成的縮略圖默認寫在配置目錄裏。它們是可以重新生成的東西，而配置目錄是版本
控制的內容。

標籤數據庫是你自己輸入的，重新生成不出來，所以和縮略圖分開放。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(setq image-dired-dir (ginshio-cache "image-dired/")
      image-dired-db-file (ginshio-data "image-dired-tags"))
#+end_src

** 鍵位

進入 dired 的路有兩條，這裏補的是第二條：從當前文件跳進它所在的目錄，光標停在這個文
件上。出廠的 =C-x C-j= 隨全域一起沒了。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(ginshio-leader-define
 "f d" #'dired
 "f j" #'dired-jump
 "f J" #'dired-jump-other-window)
#+end_src

其餘都在 dired 緩衝區裏面，用的是它自己的單鍵映射。

| 鍵         | 做什麼                             |
|------------+------------------------------------|
| ~M-m f d~    | 列出一個目錄                       |
| ~M-m f j~    | 跳到當前文件所在的目錄             |
| ~M-m p d~    | 列出項目根目錄                     |
| ~m~ ~u~ ~U~      | 標記 / 取消 / 全部取消             |
| ~% m~        | 按正則標記                         |
| ~t~          | 反轉標記                           |
| ~C~ ~R~ ~D~      | 複製 / 改名 / 刪除標記的           |
| ~r~          | 進入可編輯模式，批量改名           |
| ~=~          | ediff 標記的文件                   |
| ~E~          | 交給桌面上註冊的程序打開           |
| ~(~          | 顯示或隱藏權限、屬主、大小         |
| ~i~          | 就地展開子目錄                     |
| ~A~ ~Q~        | 在標記的文件裏搜索 / 搜索並替換    |
| ~!~ ~X~        | 對標記的文件跑一條 shell 命令      |

** 自檢項

列目錄的開關依賴 GNU coreutils。這件事失敗時的樣子是 dired 整個打不開，而錯誤信息是
=ls= 抱怨一個它不認識的選項——離「配置寫了一串它不支持的開關」還有幾步推理。

#+begin_src emacs-lisp :tangle "lisp/ginshio-file.el"
(ginshio-doctor-declare 'file "GNU ls"
                        (lambda ()
                          (eq 0 (call-process insert-directory-program nil nil nil
                                              "--group-directories-first" "--version")))
                        :note "the listing format this module asks for"
                        :remedy "zypper install coreutils")
#+end_src
